# Saras.WebSearch — Zero-Tab Intelligent Web Search

> Platform: VANI-xAI (Vāṇī Adhyātmik Navīn Intellect)  
> URL: https://vani-nzdrsr.web.app/saras_web_search.html

Saras.WebSearch is a next-generation in-browser search interface designed to eliminate tab clutter.

## Features
- **Zero-Tab Search**: Instant queries directly inside the workspace without opening external browser tabs.
- **AI-Powered Synthesis**: Real-time LLM summarization and source citations for fast verification.
- **Visual Citations**: Direct source URLs, domain badges, and contextual snippets.
