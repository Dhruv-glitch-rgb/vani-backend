# VANI-xAI: Vāṇī Adhyātmik Navīn Intellect

> "Don't Assume, Verify."  
> Official Deployment: [https://vani-nzdrsr.web.app/](https://vani-nzdrsr.web.app/)

VANI-xAI (Vāṇī Adhyātmik Navīn Intellect) is a futuristic, web-native artificial intelligence platform and desktop agent environment. It combines real-time voice synthesis, multi-modal LLM reasoning, zero-tab web search intelligence (Saras.WebSearch), cross-device Swarm synchronization, and automated desktop OS control.

---

## 🌟 Core Features & Modules

### 1. Saras.WebSearch (`/saras_web_search.html`)
- Zero-tab in-browser web search engine.
- Instant summarization of live web results with direct citations.
- Built-in multi-source synthesis avoiding tab clutter.

### 2. Saras_VANI.Chat (`/saras_vani_chat.html`)
- Real-time multi-device connected AI chat rooms.
- Session memory, persistent message history, and audio transcription.

### 3. Saras_VANI.Search / Radar (`/saras_vani_search.html`)
- Local network radar scanner.
- Discovers and pairs nearby VANI nodes, smartphones, and workstations for cross-device telemetry.

### 4. Desktop Automation & Helper (`/api/command`)
- Voice-activated hands-free desktop control.
- Application launching (Chrome, VSCode, Notepad, etc.).
- Workstation locking, volume control, and automated script execution.
- Real-time screenshot capture and vision analysis.

### 5. Local LLM Offline Mode (`/api/local-llm/*`)
- Connects directly to local Ollama, LM Studio, or vLLM instances for 100% private, offline inference.

## 🤖 Voice & Text Command Syntax

| Command Type | Example Voice / Text Prompt | Action Performed |
| :--- | :--- | :--- |
| **Web Search** | `search latest quantum computing benchmarks` | Opens Saras.WebSearch and parses live results |
| **Open App** | `open visual studio code on desktop` | Launches target desktop software |
| **Vision Analysis** | `take screenshot and explain what is on screen` | Captures display and invokes multi-modal vision LLM |
| **System Control**| `mute volume` or `lock workstation` | Adjusts system volume or locks desktop session |
| **WhatsApp Call** | `whatsapp voice call to 9876543210 on desktop` | Initiates WhatsApp desktop communication |
| **Autonomous Goal**| `goal: research and summarize top 5 machine learning papers` | Triggers multi-step autonomous agent loop |
