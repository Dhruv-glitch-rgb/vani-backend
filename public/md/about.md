## 🌟 Mission & Philosophy

VANI-xAI (Vāṇī Adhyātmik Navīn Intellect) is a futuristic artificial intelligence ecosystem engineered to unify real-time conversational voice synthesis, zero-tab web discovery, local edge intelligence, and desktop automation.

The name draws upon Sanskrit wisdom:
- **Vāṇī (वाणी)**: Articulate speech, voice synthesis, and communication.
- **Adhyātmik (आध्यात्मिक)**: Deep reflective reasoning and consciousness.
- **Navīn (नवीन)**: Modern, next-generation AI innovation.

---

## 🏛️ Core Capabilities

1. **Saras.WebSearch (`/saras_web_search.html`)**: Zero-tab in-browser web search with real-time AI summarization and link citations.
2. **Voice Synthesis & Vision Analysis**: Real-time Web Speech recognition and multi-modal screen inspection.
3. **Autonomous Agent Reasoning (`/api/command`)**: Multi-step goal execution with persistent memory.
4. **Local LLM Privacy Mode (`/api/local-llm/*`)**: 100% offline edge inference via Ollama, LM Studio, or vLLM.
