## Overview
**Quantum Beam** is an indigenous, ultra-fast peer-to-peer (P2P) file and media drop system running natively in browser via WebRTC `RTCDataChannel`. Operating with zero electronic waste and zero commercial cloud storage reliance, it delivers instant AirDrop-style file sharing between phones, laptops, and lab computers.

## Key Specifications & Architecture
- **Multi-File Batch Queue**: Queue multiple photos, documents, and code files simultaneously with interactive staging, individual removal, and batch telemetry.
- **Quick Note & Text Beam**: Instant text, prompt, math derivation, or URL beaming directly to paired peer devices with one-click clipboard copying.
- **Universal In-App Media Preview**: Rich in-modal previewer for images, 4K videos, audio tracks, PDFs, and code files without browser popup blocker interruptions.
- **Cryptographic Bit-Integrity**: Automatic SHA-256 checksum calculation and verification ensuring 100% bit-for-bit file authenticity with verified badges.
- **Web Audio Sci-Fi Sound FX**: Procedural real-time synthesizer providing acoustic feedback for link establishment, streaming pulses, and transfer completion (with mute toggle).
- **Global Clipboard Catcher**: Press `Ctrl+V` anywhere to capture clipboard screenshots and files for instant transmission.
- **Sovereign Local Storage Integration**: Automatically archives received media to `E:\BoVxAi DB\<V.A.N.I-xAI-USER-ID>\beam_media\` isolated by authenticated user partition.
- **Flow-Control Backpressure**: 16KB chunking with 256KB dynamic threshold buffering ensures maximum throughput without browser memory overflows.
- **Dual Engine Signaling**: Multi-STUN WebRTC SDP handshake coordinated via Firestore with automatic local Flask relay (`/api/beam/signal`) fallback.
- **Pairing Modes**: One-Time Pair Code (`BoVxAi_V.A.N.I-XXXX:00000`), real-time camera QR scanner (Html5Qrcode), and one-click URL sharing.
