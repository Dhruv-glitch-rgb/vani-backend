## Overview
**Quantum Beam** is an indigenous, ultra-fast peer-to-peer (P2P) file and media drop system running natively in any browser via WebRTC `RTCDataChannel`. 

## Key Specifications
- **No File Size Limits:** Transfer files from 10KB up to multi-gigabyte 4K videos or zip archives.
- **Zero Cloud Storage Overhead:** Direct browser-to-browser transmission with zero upload to third-party cloud storage (Firebase Storage).
- **Sovereign Local Storage Integration:** Received files can auto-archive straight to `E:\BoVxAi DB\<V.A.N.I-xAI-USER-ID>\beam_media\`.
- **Flow-Control Backpressure:** 64KB chunking with dynamic threshold buffering ensures seamless speed without memory overflows.
- **Pairing Modes:** Instant 6-digit Quantum Beam PIN or zero-friction mobile QR code scan.
