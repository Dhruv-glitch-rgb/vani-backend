# Privacy Policy — VANI-xAI

> Last Updated: August 2026  
> URL: https://vani-nzdrsr.web.app/privacy

## 1. Data Collection & Processing
VANI-xAI prioritizes client-side and local execution:
- Voice input is processed directly in the user browser or local audio engine.
- Local LLM mode routes prompts exclusively to your local machine (e.g., Ollama / LM Studio) without transmitting data externally.

## 2. Authentication & Preferences
User accounts and session identifiers are securely managed via Firebase Authentication and local storage. No sensitive passwords are stored in plain text.
