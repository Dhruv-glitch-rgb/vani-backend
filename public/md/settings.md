# Settings & Configuration — VANI-xAI

> Platform: VANI-xAI (Vāṇī Adhyātmik Navīn Intellect)  
> URL: https://vani-nzdrsr.web.app/settings.html

Configure your VANI-xAI preferences:
- **Local LLM Endpoint**: Set Ollama / LM Studio host URL (e.g., `http://127.0.0.1:11434`)
- **API Keys**: Configure custom OpenRouter API credentials
- **Voice Synthesis**: Adjust speaking rate, pitch, and voice models
- **Device Pairing**: Manage paired mobile and desktop nodes
