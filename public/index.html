How it Works

Interactive Command Workflow

Learn how V.A.N.I-xAI processes your prompt inputs and converts them into native OS calls:

Phase 01

Command Input

User voice transcripts are captured using Web Speech recognition, or direct instructions are entered in the input prompt.

Phase 02

Intent Parsing

The NLP parser queries the OpenRouter API (or runs local fallback regex schemas) to identify the target action and parameters.

Phase 03

Platform Routing

Routing rules dispatch execution either to local desktop PyAutoGUI scripts or USB ADB shell commands on the mobile device.

Phase 04

Response & Preview

Execution logs and screenshot captures are pulled, parsed, and displayed dynamically in your live console chat window.

Setup

Android Connection Setup

V.A.N.I-xAI auto-configures Android platform tools. Connect your phone in three steps:

01

USB Connection

Connect your Android phone to the computer using a high-quality USB cable.

02

USB Debugging

Go to Settings > Developer Options on your phone, and enable the "USB Debugging" toggle.

03

Authorize Keys

Accept the connection request dialog on your phone screen to authorize USB debugging keys.
