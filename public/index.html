How it Works

Interactive Command Workflow

Learn how V.A.N.I-xAI processes your prompt inputs and converts them into native OS calls:

Phase 01

Command Input

User voice transcripts are captured using Web Speech recognition, or direct instructions are entered in the input prompt.

Phase 02

Intent Parsing

The NLP parser queries the OpenRouter API (or runs local fallback regex schemas) to identify the target action and parameters.

Phase 03

Platform Routing

Routing rules dispatch execution locally to desktop PyAutoGUI scripts or natively in your browser.

Phase 04

Response & Preview

Execution logs and screenshot captures are pulled, parsed, and displayed dynamically in your live console chat window.
