Frequently Asked Questions

Answers to common queries regarding system controls, mobile setups, and automated messaging.

What exactly is V.A.N.I-xAI?

V.A.N.I-xAI (Vāṇī Adhyātmik Navīn Intellect) is a locally-run conversational interface companion. It allows you to use voice commands or typed text prompts to control your computer and mobile phone screens, automate calls, take screenshots, and send messages.

Do I need a Google Gemini API Key to use it?

No, an API key is completely optional! Without an API key, V.A.N.I-xAI uses a local offline regex parser to map your direct commands. If you do paste a Gemini API Key in the settings, you can speak to V.A.N.I-xAI using flexible, conversational natural language.

Why does the WhatsApp Desktop call trigger fail?

For WhatsApp calls to trigger on your computer, you **must** have the official **WhatsApp Desktop application** installed from the Windows Microsoft Store and be logged in. Browser-based WhatsApp Web does not support voice/video call protocols.

My mobile commands say "XML matching failed". Why?

This happens if the phone screen is locked or if the WhatsApp chat screen takes too long to load due to network delays. Ensure your phone screen is unlocked (no passcode lock) when launching commands. The assistant now automatically wakes the display and retries scanning up to 3 times to find UI buttons before giving up.

Where are screenshots saved?

Screenshots taken using "take screenshot" or "take mobile screenshot" are saved locally inside the `static/screenshots` folder of the project directory. They are rendered as previews inside your chat window for convenience.
