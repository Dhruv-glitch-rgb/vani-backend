Authentication & Request Headers

The VANI-xAI API supports unauthenticated testing for public search and diagnostic routes. For custom LLM execution and local routing, pass the following optional HTTP headers:

Header Key Type Requirement Description
X-OpenRouter-Key string Optional Your custom OpenRouter API key for cloud model inference.
X-Force-Local boolean Optional Pass true to guarantee processing stays 100% offline on local Ollama/LM Studio.
X-Local-Model string Optional Target specific installed local model (e.g. llama3:latest, qwen2.5:7b).
Content-Type string Required for POST Set to application/json.

Execute Natural Language Command

POST /api/command
Public / Authenticated JSON

Processes natural language instructions, executes Saras.WebSearch queries, triggers desktop automation routines, or performs vision analysis.

Body Property Type Requirement Description
command string Required The natural language instruction or query (e.g., "search latest AI advancements").
personality string Optional Voice persona response style (human_girl, technical, concise). Default: human_girl.
execute_automation boolean Optional Whether to allow desktop automation execution if required. Default: true. 
curl -X POST https://vani-nzdrsr.web.app/api/command \
  -H "Content-Type: application/json" \
  -d '{
    "command": "search latest artificial intelligence breakthroughs",
    "personality": "human_girl"
  }'
const response = await fetch("https://vani-nzdrsr.web.app/api/command", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    command: "search latest artificial intelligence breakthroughs",
    personality: "human_girl"
  })
});
const data = await response.json();
console.log(data);
import requests

url = "https://vani-nzdrsr.web.app/api/command"
payload = {
    "command": "search latest artificial intelligence breakthroughs",
    "personality": "human_girl"
}
response = requests.post(url, json=payload)
print(response.json())

System Telemetry & Uptime

GET /api/system-stats
Telemetry JSON

Fetches live CPU load, memory utilization, platform uptime, network status, and active background threads. 

curl -X GET https://vani-nzdrsr.web.app/api/system-stats
const stats = await fetch("https://vani-nzdrsr.web.app/api/system-stats").then(res => res.json());
console.log("Telemetry:", stats);

Local LLM Status & Model Inventory

GET /api/local-llm/status
Local Inference JSON

Queries local Ollama (localhost:11434) or LM Studio (localhost:1234) daemon connectivity and enumerates available local models. 

curl -X GET https://vani-nzdrsr.web.app/api/local-llm/status

Pull / Download Local Model

POST /api/local-llm/pull
Background Job JSON

Initiates asynchronous background download of an open-weights model into the local Ollama store. 

curl -X POST https://vani-nzdrsr.web.app/api/local-llm/pull \
  -H "Content-Type: application/json" \
  -d '{ "model": "qwen2.5:7b" }'
