Authentication & Headers

All API endpoints support optional custom OpenRouter keys and offline local model flags passed via HTTP headers:

  • X-OpenRouter-Key: Optional custom API key for cloud LLM reasoning.
  • X-Force-Local: Set to true to route execution exclusively to local Ollama / LM Studio models.
  • X-Local-Model: Target specific local model (e.g., llama3:latest, qwen2.5:7b).
  • Accept: Standard content negotiation (application/json or text/markdown).

Core API Endpoints

POST /api/command
Public REST

Executes a natural language command, triggering automated desktop actions, Saras.WebSearch queries, vision analysis, or conversational chat.

Example Request (cURL):

curl -X POST https://vani-nzdrsr.web.app/api/command \ -H "Content-Type: application/json" \ -d '{ "command": "search latest artificial intelligence breakthroughs", "personality": "human_girl" }'

Example Response (JSON):

{ "success": true, "action": "saras_web_search", "query": "latest artificial intelligence breakthroughs", "message": "Searching for 'latest artificial intelligence breakthroughs' in Saras.WebSearch..." }
GET /api/system-stats
Telemetry

Returns live CPU, memory, storage, network I/O, and platform uptime metrics.

curl -X GET https://vani-nzdrsr.web.app/api/system-stats
GET /api/local-llm/status
Local AI

Checks connectivity to local Ollama / LM Studio instances and lists locally installed models.

curl -X GET https://vani-nzdrsr.web.app/api/local-llm/status

Model Context Protocol (MCP) Integration

VANI-xAI natively exposes an MCP manifest allowing Claude Desktop, ChatGPT, and autonomous coding agents to invoke VANI-xAI tools directly:

{ "mcpServers": { "vani-xai": { "url": "https://vani-nzdrsr.web.app/.well-known/mcp.json", "transport": "http" } } }
