Privacy Policy

Last Updated: August 6, 2026

1. Data Collection & Privacy First

V.A.N.I-xAI is designed as a **locally-hosted** software application. It does not gather, store, or transmit your personal data, chat records, automation logs, phone numbers, or captured screen images to any external developer databases. All variables and logs remain completely on your local computer.

2. Local Logs & Screenshots

Logs printed to the terminal console are stored in volatile local buffers for live rendering in the UI. Taken screenshots (such as desktop captures or ADB mobile screen snapshots) are saved directly to your workspace `static/screenshots` directory. They are never sent to third-party endpoints and can be cleared manually at any time.

3. Third-Party APIs (Gemini API)

When you enter a custom Google Gemini API Key, queries that you type or speak are sent directly to Google's Generative AI API to parse intent parameters. The storage, security, and usage of that query text are subject to Google's Privacy Policies.

4. ADB & Android Debug Security

Android mobile integration operates entirely over a direct USB cable link using local ADB commands. You control which phone is authorized. No remote server or third-party connections are initiated during ADB shell operations.

5. Local Browser Storage

The web console preserves configuration values (such as your optional API key) in your browser's local sandbox storage (`localStorage`). This is sandboxed inside your local client browser and never uploaded anywhere.
